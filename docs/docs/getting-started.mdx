# React Native Interactive Walkthrough

React Native Interactive Walkthrough is an open source library for building interactive walkthroughs in React Native - without touching the native side.

Get started building by installing rn-interactive-walkthrough or by following the [Usage](./guides/usage.mdx) guide to learn the main concepts.

## Getting Started

Get started by **installing the library**.

import Tabs from "@theme/Tabs";
import TabItem from "@theme/TabItem";

<Tabs>
  <TabItem value="npm" label="npm" default>
    <pre>npm install rn-interactive-walkthrough</pre>
  </TabItem>
  <TabItem value="yarn" label="yarn">
    <pre>yarn add rn-interactive-walkthrough</pre>
  </TabItem>
  <TabItem value="pnpm" label="pnpm">
    <pre>pnpm add rn-interactive-walkthrough</pre>
  </TabItem>
</Tabs>

### Requirements

The library relies on a few peer dependencies. Make sure these are installed in
your project:

| Package                          | Minimum version |
| -------------------------------- | --------------- |
| `react`                          | 17.0            |
| `react-native`                   | 0.63            |
| `react-native-reanimated`        | 3.0             |
| `react-native-safe-area-context` | 4.0             |

:::note

The library is only tested against the latest React Native version, but these
are the lowest versions it is known to work with.

:::
